An independent experimental implementation of MeanFlow speech restoration, with PyTorch models, streaming inference, training pipelines, and evaluation tools.

This is ongoing research; it is not an official implementation or a validated reproduction of the paper's results.

[View the source code and research status](https://github.com/quangng2000/rmfsr).
