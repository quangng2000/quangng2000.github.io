I'm a **contributor and maintainer of LemmaScript**, an open-source verification toolchain for TypeScript.

LemmaScript lets developers write TypeScript with specification annotations and generates code for verification in Dafny or Lean 4. The workflow connects application code, specifications, and proofs, bringing formal methods into TypeScript development.

The project is a tech preview, with language support and tooling continuing to evolve.
